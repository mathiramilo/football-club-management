## Optional, per developer (not committed)

- **Hallmark** ([nutlope/hallmark](https://github.com/nutlope/hallmark), MIT): an alternative to `design-taste-frontend` and Impeccable for a marketing landing page, once one is specified. Don't commit `.hallmark/` or its CSS stamp comments.
- **Jakub Krehel's `better-*` skills** ([jakubkrehel/skills](https://github.com/jakubkrehel/skills), MIT): web color, layout, typography and copy reviews. Its advice to rename `--color-primary` to `accent` clashes with shadcn's tokens.
- **Callstack's react-native-best-practices**: full profiling walkthroughs. Its examples assume Callstack's `agent-device` CLI; the animation reference is on Reanimated 4, the bottom-sheet one still on Reanimated 3.
- **Software Mansion's `gestures` skill** ([software-mansion-labs/skills](https://github.com/software-mansion-labs/skills)): useful for Gesture Handler 3. Not vendored because the repo has no LICENSE file (its README says MIT).
- **`next-dev-loop`** ([vercel/next.js](https://github.com/vercel/next.js) `skills/`): drives the running app in a browser. Needs a global `agent-browser` install.
- **Vercel plugin skills** (`vercel:nextjs`, `vercel:next-cache-components`, …): fine to keep. `vercel:shadcn` and `vercel:react-best-practices` are turned off in `.claude/settings.json` because the vendored `shadcn` and `react-best-practices` skills replace them.

## Updating a vendored skill

Download the new upstream version into a scratch folder, read every changed file, re-apply the changes in the table above, update the pinned commit here, and ship it as its own PR. For `impeccable`, also check that `scripts/VERSION` (the engine version the launcher downloads) and the `.gitignore` block still match upstream; never update it with `npx impeccable update`.
