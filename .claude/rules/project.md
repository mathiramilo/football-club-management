# Project context

Football Club Management (working name, OQ-03) is a mobile app (iOS/Android), a web app and an API for amateur and semi-professional football clubs in Uruguay and Argentina. It covers attendance and RSVP, attendance analytics, player wellness, an exercise library and session planning, routines and nutrition, and an AI coaching assistant, all organized by club and category.

## Monorepo (pnpm workspaces + Turborepo)

```text
apps/api/            NestJS REST API + worker entrypoint (same image, two process types)
apps/web/            Next.js App Router: staff portal, public SSR pages, player web fallback
apps/mobile/         Expo (React Native) app, Expo Router
packages/contracts/  Zod schemas, enums, error codes → OpenAPI
packages/api-client/ Typed client + TanStack Query hooks generated by Orval (never hand-edited)
packages/domain/     Pure, framework-free business rules shared by API and clients
packages/i18n/       ICU message catalogs (es first, en in R3)
packages/ui-tokens/  Design tokens → Tailwind / NativeWind preset
packages/config/     tsconfig, ESLint, Prettier presets
docs/                Product and technical specs
```

Contract flow: `packages/contracts` → API validates with the same schemas → OpenAPI document → Orval → `packages/api-client` → web and mobile.
