# football-club-management

Mobile app (iOS/Android), web app and server for amateur and semi-professional football clubs. Covers attendance and RSVP, attendance analytics, player wellness, an exercise library and session planning, routines and nutrition, and an AI coaching assistant, organized by club and category.

Product and technical documentation lives in [`docs/`](docs/README.md). Start with the [initial product review](docs/product/00-initial-review.md).
